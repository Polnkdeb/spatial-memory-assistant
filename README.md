# Spatial Memory Assistant

Проект по компьютерному зрению для поиска объектов на видео с помощью YOLOv8.

Программа:

* извлекает кадры из видео;
* выполняет детекцию объектов на каждом кадре;
* сохраняет результаты в индекс;
* позволяет искать кадры по названию объекта.

Можно найти все кадры, на которых найдены объекты из набора классов COCO.

## Структура проекта

```text
src/
├── frame_extractor.py   # извлечение кадров из видео
├── detector.py          # детекция объектов YOLOv8
├── indexer.py           # построение индекса
├── query.py             # поиск и отображение результатов
└── coco_classes.py      # список классов COCO

main.py                  # запуск 
```

## Используемые технологии

* Python
* OpenCV
* Ultralytics YOLOv8
* JSON
* tqdm


## Запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```

Перед запуском необходимо указать путь к видео в файле `main.py`.
